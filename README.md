# FEE-Project-AROMATICA
Aromatica is a premium, cinematic static site for a luxury coffee‑restaurant brand. Built with pure HTML, CSS, and vanilla JavaScript, it features glass‑morphism UI, animated hero, interactive reservation map, orders dashboard, and a front‑end login with a localStorage‑based “Forgot Password” modal. All assets are local, no external dependencies.
